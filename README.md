## 系统组成（抽象）

```
企业场景输入(XML 接口实例) ──► xml_adapter（解析为 Scenario 领域模型）
        │                          │
        │                          ├─► business.py（版本化基础资料：产线/节拍/日历/缓冲/切换，校验与准入）
        │                          │
        ▼                          ▼
  production_sim.py(4200辆·1000扰动蒙特卡洛)   aps-fullchain（小场景全链路：净额→聚合→分配→策略→仿真→校验→评价）
        │                          │
        └───────────┬──────────────┘
                    ▼
        server_integrated.py（REST + SQLite + 后台任务 + 权限工厂隔离 + 进度事件）
                    │
                    ▼
        web/ 工作台（计划管理 → 场景选择 → 计划依据 → 计算进度 → 调度结果 → 参考排程 → 审批）
```

- **小场景链路（aps-fullchain）**：面向 12–17 辆演示场景，验证需求冲销、分层计划、多车间派工、有限缓冲正阻塞、独立校验与多策略比较（EDD/颜色感知/负荷均衡/ALNS）。
- **生产量级链路（production_sim）**：面向 4200 辆、5 日双班，秒级等效瓶颈流水模型；对到货、加工时间、设备故障做 1000 次联合扰动抽样，四方案共用同一样本（CRN），输出均值/分位数/置信区间。统计结果不可提交审批。
- **页面原则**：工厂用户只看业务语言（计划依据、业务进度、方案指标、参考排程）；实验计数、随机种子、分位数与样本明细仅存后台日志。

## 运行方式

```bash
# 生产量级演示（推荐，含已验收数据）
APS_DB='<本目录>/08-运行说明/acceptance-production.sqlite3' \
python3 '<本目录>/05-系统实现/server_integrated.py' --port 18746
# 打开 http://127.0.0.1:18746/?v=prod-operations-2#/plans
```

- 身份经页面右上角切换：planner-a(F1) / planner-b(F2) / manager / engineer / admin。
- 运行前将 `04-后端算法内核/aps-fullchain`、`06-演示场景数据/test-suites-xml`、`05-系统实现` 放到同一根目录（详见《运行说明》）。
- 端口 18745 为旧验收环境，勿与 18746 混用。
