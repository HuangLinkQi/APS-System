# 生产量级场景与 1000 次仿真说明

> 实现文件：`aps-v2/production_sim.py`（本次交付，仅本文件；不改 server/web）。
> 性质：**等效瓶颈流水离散事件仿真（秒级）**，非工位级连续流水线数字孪生；不冒充工厂实测精度。所有分布参数为**研究假设**，逐条标注，不得当作现场标定值。

---

## 1. 场景量级与真实日历（本次修订的核心）

- **自然日历**：5 个自然日，每自然日 `86400s`；每天两个 460 分钟工作窗口：
  - 06:00–13:40（27600 s）
  - 14:20–22:00（27600 s）
- `horizon = 第 5 天 22:00`（绝对值 `HORIZON_SEC`）。
- 加工在**非工作窗口暂停顺延**；到货、故障、订单释放、交期全部使用**同一个自然日墙钟**口径。
- **关键澄清**：`自然日=86400s` 与"单班 460min / 双班 920min 工作窗口"是两个量纲，绝不混作一根数轴（修正旧版把 276000s 当连续工作轴的错误）。
- 目标日平衡：单班约 452 台、双班约 904 台；周目标 **4200 台**。
- 平均每台可用产能：`工作周总秒 / 4200`，默认各车间基础节拍 W=62s / P=58s / A=60s（等效单车间产能槽，见 §3 假设）。

## 2. 模型定义（等效瓶颈流水，非工位数字孪生）

3 车间 `W → P → A` 串行，车间之间并行运行、各有有限缓冲：

| 车间 | 含义 | 每车开工扣减 BOM |
|---|---|---|
| W | 焊装 | STEEL 或 ALUM（按 config.raw） |
| P | 涂装 | PAINT |
| A | 总装 | BATTERY + MOTOR |

- 缓冲：`W->P`、`P->A` 各一张有限容量队列（默认 40）。
- **正阻塞不丢车**：上游加工完毕而下游缓冲满 → 上游 `blocked` 持有该车（占产能槽），直至下游取走；阻塞时长单独统计。
- **物耗真实**：每工序开工时按配置 BOM 扣减对应原料；库存不足则停在工序前待料，绝不产生负库存、不丢车。
- **拔出车**：`is_pullout` 配置的车型在 P 完成后出线（不进 A、不耗电池）。
- **故障**：每样本每车间独立 **Poisson 故障台数**（指数型 MTBF 到达）+ 指数修复时长，可为零；故障窗为墙钟，加工在其间暂停顺延。调度贪心无前瞻，不用整周故障预知做重排。
- **非数字孪生声明**：单车间为单台产能槽（瓶颈/节拍口径），非多工位连续积放链微观模型；不得伪装成多工位数字孪生或工厂实测精度。

## 3. 随机项与公平比较（CRN）

`sample_reality(scenario, seed, ...)` 一次性生成，**同一 Reality 供全部策略复用**（CRN）：
1. 到货延迟：每批 `arrival_sigma` 的加性高斯扰动（对绝对到货时刻）。
2. 逐车逐工位耗时乘子：精确对数正态，实际变异系数即 `process_cv`（非 log-sigma）：
   `sigma = sqrt(log(1+cv²))`，`mu = −sigma²/2`，乘子 = `exp(mu + sigma·Z)`，`Z~N(0,1)`，
   故 `E[mul]=1` 且 `CV(mul)=cv`。
3. 故障：固定区间 `[0,horizon]`，各车间独立 `N~Pois(failure_expected_per_line)`，
   到达点为条件 `Uniform(0,horizon)` 排序（标准/无偏泊松过程，避免"指数到达+截断"导致的强度失真）；
   修复时长指数、末端 `clamp` 到 horizon；**可为零**。重叠窗由仿真 `_advance` 的 in-fault 跳转天然合并处理。

每样本 `seed = seed_base + idx` 完全可复现；策略间不重采样。

**参数默认值与来源（假设，非实测）**：`arrival_sigma=720s`、`process_cv=0.08`、`failure_expected_per_line=1.1`（每周/线台数、泊松均值）、`repair_mean_min=40`。以上均为研究假设。

### 策略（新等效内核，非旧 ALNS / 原算法）

| 策略 | 语义 |
|---|---|
| EDD | 交期优先 |
| COLOR_GROUP | P 优先同色，减换色切换 |
| LOAD_BALANCE | A 交替车型，平准总装负荷 |
| OPTIMIZED | **名义（无扰动）候选选优**：生成若干确定性候选（优先级/EDD/颜色分组/车型分组/确定性 2-opt），在名义现实上一一仿真，按 `完成率→整体按期→条件按期→阻塞→makespan` 选最优固定序列；**全部样本共用同一固定序列、全阶段( W/P/A )按该序列Index执行**，不随样本重优化、不读未来。 |

## 5. 输入契约（build_production_scenario / ProductionScenario）

`ProductionScenario`：`scenario_id`, `orders`, `configs`, `deliveries`, `initial_stock`, `buffer_cap`, `pullout_vins`, `calendar: WorkCalendar`。

- `Order(vin, config, release_at, due_at, priority, model, color)` —— 时间为绝对秒（墙钟）。
- `ConfigDef(config_id, model, color, raw(STEEL/ALUM), switch_sec, is_pullout, process_sec{W,P,A})`；`ConfigDef.bom(stage)` 返回工序→物料消耗。
- `SupplyDelivery(batch_id, material(STEEL|ALUM|PAINT|BATTERY|MOTOR), qty, planned_at)`。
- `WorkCalendar.to_dict()` 给出自然日/班窗口/horizon。

## 6. 统计口径与准出（本次修订）

| 指标 | 定义 | 分母 |
|---|---|---|
| completion_rate | 完成数 / 有效需求 | 全部有效订单（含未完成） |
| overall_on_time_rate | 准交完成 / 有效需求 | 全部有效订单 |
| conditional_on_time_rate | 准交完成 / 已完成 | 已完成（**completed==0 → None**，不为 0） |
| mean_tardy_over_completed_sec | 拖期和 / 已完成 | 全部已完成 |
| mean_tardy_over_late_sec | 拖期和 / 拖期台数 | 仅拖期者（单列，不与上者混称"全部"） |

- 每策略聚合 `mean/std/p05/p95/ci95_low/ci95_high`（正态近似 `1.96*std/sqrt(n)`）；`conditional_on_time` 等可能为 None 的指标单列 `n_valid / n_total`，明确空计数。
- `final_status`：仅全部样本执行完成且**无 error** 时为 `complete`；任何 error → `not_complete` 并保留 `errors`；`should_cancel` 命中 → `cancelled`，均不以未完成冒充完成。

## 7. 流式回调与可复现性（本次修订）

`run_samples(sc, cfg, progress=None, on_sample=None, should_cancel=None, keep_sample0_timeline=True)`：
- `progress(done, total)`：每样本完成。
- `on_sample(idx, n_total, sample_record, timelines_or_none)`：每样本流式；`timelines_or_none` 仅在 idx==0 且 keep_sample0_timeline 时非 None。
- `should_cancel()` → True 提前停。
- 返回含 `cancelled / n_completed / running / strategy_stats / sample_results / sample0_timeline / errors`。
- 每样本 `Reality.to_dict()` 保存**完整**到货延迟、扰动摘要、故障窗、`alg_version` 与采样参数（修复：不再只给 count 而无值）；`sample0` 保留每车时间线供页面交互。

## 8. 性能估算（标注 估算，非实测定）

本机 Python 3 实测（默认 4200 台）：单策略单运行约 0.05–0.07 s；外推 1000 样本×4 策略约 3–4 分钟（**估算**，未在目标环境验证，不得宣称为工厂基准）。规模接近 O(N)（vin→Order 查表；OPTIMIZED 用固定序列堆；布尔BOM 快速）。
