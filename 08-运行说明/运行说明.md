# 运行说明

## 本目录是干什么的

存放 APS 演示系统的运行资源：演示数据库和启动方法。目录里没有代码，代码在 `05-系统实现/`，算法在 `04-后端算法内核/`。

## 文件说明

| 文件 | 说明 |
|---|---|
| `acceptance-production.sqlite3` | 演示数据库（SQLite 格式）。内含已验收的测试计划、输入快照、基础资料版本和 1000 次仿真的完整结果（4200 辆 × 4 方案），以及取消测试的部分结果。直接用它启动即可复现验收时的页面内容。 |

> 如果 macOS 访达把这个文件显示成 "Circle Lite" 或无类型图标，是文件扩展名 `.sqlite3` 未被关联到某个程序所致，文件本身是标准 SQLite 3 数据库，程序能直接读，不影响运行。

## 启动步骤

1. 将本资料包中的 `04-后端算法内核/aps-fullchain`、`06-演示场景数据/test-suites-xml`、`05-系统实现` 三个目录放到同一根目录下（保持相对引用）。
2. 在该根目录执行：

```bash
APS_DB='<资料包>/08-运行说明/acceptance-production.sqlite3' \
python3 '<资料包>/05-系统实现/server_integrated.py' --port 18746
```

3. 浏览器打开：`http://127.0.0.1:18746/?v=prod-operations-2#/plans`

## 页面身份

右上角"模拟身份"切换，均为演示身份，非生产鉴权：

| 身份 | 权限 |
|---|---|
| 计划员 A · F1 | 新建计划、选择场景、开始计算、提交审批 |
| 计划员 B · F2 | 只能看到 F2 工厂 |
| 生管主管 | 待审批列表中批准 |
| 工艺负责人 · F1 | 基础数据（产线/节拍/日历/切换）维护 |
| 系统管理员 | 仅系统说明，无业务数据 |

## 快速演示路径（推荐给讲解用）

1. 计划员 A 打开已有计划（如"进度验收-1000"）→ 查看"调度结果"四方案指标对比。
2. 点"查看参考排程（单次模拟）"→ 按产线（焊装/涂装/总装）和车号筛选时间表。
3. 新建一个计划 → 场景弹窗选"生产量级周计划 · 4200辆" → 开始计算 → 观察业务进度 → 取消，展示计数保留。
4. 切换工艺负责人 → 打开"基础数据"演示节拍/日历维护；切回计划员演示"引用最新基础数据"。
5. 切换生管主管 → 待审批批准；切换计划员 B / 管理员演示权限隔离。

## 注意事项

- 端口 18746 为当前演示环境；18745 是历史小场景验收环境，勿混用。
- 该库为本机演示数据，全部指标是仿真估计；提交/批准仅记录演示状态，不下发生产指令。
- 不要把删除数据库当重置手段；如需全新演示，另建空库文件换一个 `APS_DB` 路径启动即可。
